Get started

The public binary download for AttaLambda v0.8.0 supports Linux x86-64. It includes its own Racket runtime; you do not need to install Racket separately.

Find the downloads on GitHub releases, or inspect the source repository. These instructions were tested with v0.8.0.

1. Download and verify

Save both files in the same directory:

  • attalambda-0.8.0-linux-x86_64.tar.gz
  • SHA256SUMS

From that directory, check the archive’s checksum:

sha256sum -c SHA256SUMS

Expected output

attalambda-0.8.0-linux-x86_64.tar.gz: OK

Continue only if the archive reports OK.

2. Extract and run

tar -xzf attalambda-0.8.0-linux-x86_64.tar.gz
cd attalambda-0.8.0-linux-x86_64
./bin/attalambda --version

Version output

AttaLambda 0.8.0

Keep the extracted distribution together, including its bin/ and lib/ directories. Run the included hello example:

./bin/attalambda examples/hello.attl

Output

Hello from AttaLambda.

3. Write a program

Save this as hello.attl in the extracted distribution directory. The filename must end in .attl, and the first line must be exactly #lang attalambda.

#lang attalambda

(print "Hello, world.")

From that same directory, run:

./bin/attalambda hello.attl

Output (no trailing newline)

"Hello, world."

print renders a string with quotation marks and does not add a newline. The included hello example instead uses stdout with an explicit newline.

4. Try the interactive shell

From the extracted distribution directory, start the shell:

./bin/attalambda --no-history

The atta> prompt means it is ready for an expression. Enter each line below separately, without a #lang line:

(add 1/3 1/6)
(def twice x = (add x x))
(twice 21)

Results (the definition itself is silent)

=> 1/2
=> 42

Definitions remain available for later entries. Enter :help to see commands, :reset to discard session definitions, or :quit to leave. Unlike file execution, the shell automatically prints expression results, so these examples need no print.

--no-history disables persistent source history. Starting ./bin/attalambda without that option enables history. For redirected input, use ./bin/attalambda --repl --no-history; that mode emits results without interactive prompts.

Automatic printing supports finite tagged data. Before evaluating a raw function value, enter :echo off: automatic rendering of untagged functions is unspecified and can fail or keep evaluating.

Keep going

Run ./bin/attalambda --help for command-line usage. Try the examples, learn how the language grows from lambda calculus, or use the language overview.
