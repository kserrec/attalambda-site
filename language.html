The language

AttaLambda builds ordinary computation from pure, untyped lambda calculus, adds readable syntax and runtime contracts, and uses a separate host boundary for effects. This page is a concise overview of version 0.8.0. Learn develops the ideas from the ground up.

Computational model

Variables, unary lambda abstraction, and application form the computational core: refer to a value, define a one-argument function, and apply it. Evaluation is lazy: values are evaluated when needed. Data and ordinary library operations are encoded with functions.

Learn: the three building blocks.

Syntax and sugar

Program files end in .attl and begin with #lang attalambda. In an application, the function comes first: (add 2 3).

(def square x = (mult x x))
Names a value or function. Ordinary self-recursive definitions are rejected.
(lambda (x y) (add x y))
Creates a function. Multiple parameters become nested unary lambdas; multiple-argument calls apply one argument at a time.
(let ((x 2) (y (add x 3))) (list x y))
Introduces local names in sequence; later bindings can use earlier ones.
(list 1 2 3)
Builds a List; (list) is NIL.
(cond ((eq x 0) 1) (else x))
Selects a branch and requires a final else.

These are syntax fragments; names such as x need a binding in the surrounding program. Learn: how def expands.

Values and runtime types

Ordinary public data values carry a type tag and payload in a lambda-encoded pair. Tags identify Error, Bool, List, Result, Char, String, Rat, Unit, Byte, Option, and Map. Public TRUE and FALSE carry the Bool tag; public if checks it.

Public operations check their required argument tags at runtime and return Errors on mismatches. This does not constitute a compile-time static type system. Ordinary functions are untagged lambdas; there is no public Function or Any tag.

Learn: objects as selector lambdas and runtime checking.

Exact numbers

Numbers are exact Rats: a signed numerator over a positive denominator, reduced to lowest terms. Whole numbers are Rats too. Their magnitudes use binary digit lists. Church numerals serve as small tags and metadata, rather than the ordinary arithmetic representation.

add, sub, and mult return Rats; comparisons such as eq and lt return Bools. div, recip, and exp return Results for arithmetic success or failure, such as division by zero. Wrong argument types produce Errors.

Run an exact addition, or learn the numeric representation.

Composite data

Lists link a head value to a tail List, ending in NIL. Operations include cons, head, tail, map, filter, and reduce. Strings, characters, bytes, and conversion between strings and byte lists are also available.

Options represent presence or expected absence: some and NONE. Use option-case to select what happens in each case. Results represent success or failure: make-ok, make-err, is-ok, is-err, unwrap-ok, and unwrap-err. An Err holds an Error.

Maps associate keys with values. Updates return new Maps while preserving earlier values; lookup returns an Option.

Learn the structures: List, Option, and Result.

Errors

An Error is a tagged value with a root describing the original problem and a frame List carrying context from checked operations. Operations receiving an Error can propagate it with added context. Error rendering turns that structure into a diagnostic; it is not the same as throwing a Racket exception.

Learn: a real type mismatch and its structure.

Recursion

rec defines a function that can call itself. It expands through a fixed-point combinator built from lambdas and application. A self-recursive ordinary def is intentionally rejected.

Run factorial, or learn how the recursive connection works.

Effects and the host

Standard output, line input, file access, TCP networking, and process exit cross the host boundary. The host validates encoded requests, converts their data, and performs the external actions. HTTP request parsing and response rendering are provided by the language library.

print renders a value and passes the text to stdout. It includes quotation marks when rendering strings and adds no newline. stdout writes a String's contents directly, including any supplied newline.

(read-line UNIT) returns a Result: Ok containing Some line, Ok containing None at end of input, or Err on failure. Learn: the host boundary.
