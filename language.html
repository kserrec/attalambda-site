The language

AttaLambda keeps a small computational foundation while making it practical to write and run programs.

Three building blocks

Ordinary computation reduces to variables, unary lambda abstraction, and application: referring to a value, defining a function of one argument, and applying a function to an argument. The friendlier source syntax expands into these building blocks.

Readable syntax

def names a value or function; lambda creates a function. Multiple arguments are shorthand for nested unary functions: (lambda (x y) (add x y)) behaves as (lambda (x) (lambda (y) (add x y))). Calls apply arguments one at a time.

let introduces local names in sequence, so later bindings can use earlier ones. list constructs a list, and cond selects a branch and requires a final else.

#lang attalambda

(def add-two = (lambda (x y) (add x y)))

(print
  (let ((x 2) (y (add x 3)))
    (cond ((eq y 5) (list x y (add-two x y)))
          (else (list)))))

Output (no trailing newline)

[2, 5, 7]

Exact numbers

Numbers are exact rationals: a signed integer numerator over a positive denominator, reduced to lowest terms. Adding 1/3 and 1/6 produces 1/2. The natural-number magnitudes underneath use binary digit lists, rather than unary Church numerals that encode a number by repeating a function that many times.

Types at runtime

Ordinary data values carry tags identifying their types. Public operations check the types they expect while the program runs and produce error values when those contracts fail. This is runtime type checking, not a compile-time static type system: AttaLambda remains untyped lambda calculus underneath.

Recursion

Use rec for a function that calls itself. It expands through a fixed-point combinator, a function that expresses recursion using lambdas and application. Ordinary self-recursive def bindings are intentionally rejected.

#lang attalambda

(rec factorial n =
  (if (eq n 0)
      1
      (mult n (factorial (sub n 1)))))

(print (factorial 5))

Output (no trailing newline)

120

Effects and the host

Writing to standard output, accessing files, using TCP networking, and exiting a process cross a controlled host boundary. AttaLambda builds requests; the host validates them and performs the external actions. The pure computation and the effects have distinct roles.

print converts a value to text and passes it to stdout. It includes quotation marks when rendering strings and does not add a newline. stdout writes a string’s contents directly, including any newline you supply.

Beyond the basics

The language includes lists, exact arithmetic, strings and characters, and conversion between strings and bytes. Options represent a value or its absence; Results represent success or expected failure. Persistent Maps return new maps when updated, preserving earlier values.

File operations, TCP networking, and HTTP request parsing and response rendering are also present. The repository examples show these capabilities together.

Learn the foundation

New to lambda calculus? Raúl Rojas’s A Tutorial Introduction to the Lambda Calculus is a concise introduction to the machinery underneath AttaLambda. The linked PDF is hosted by the University of Texas at Dallas.
