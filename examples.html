Examples

Each program is complete. Save it in a file ending in .attl and follow Get started to run it. These outputs were observed with AttaLambda v0.8.0. The examples use print, which does not add a trailing newline.

Hello world

Print a string; its rendered form includes quotation marks.

#lang attalambda

(print "Hello, world.")

Output

"Hello, world."

Exact fractional arithmetic

Add two fractions and get an exact, reduced fraction back.

#lang attalambda

(print (add 1/3 1/6))

Output

1/2

Mapping over a list

Pass square as a value to map, which applies it to each list element. Learn how Lists are represented.

#lang attalambda

(def square x = (mult x x))

(print (map square (list 1 2 3 4)))

Output

[1, 4, 9, 16]

Recursion

Define factorial with rec and apply it to a small nonnegative integer. Learn how rec builds the recursive connection.

#lang attalambda

(rec factorial n =
  (if (eq n 0)
      1
      (mult n (factorial (sub n 1)))))

(print (factorial 5))

Output

120

Larger examples

The language repository includes complete examples for AttaLambda v0.8.0:

  • File round trip writes a file and reads it back. Run it in an empty scratch directory: it creates or replaces attalambda-round-trip.txt.
  • HTTP example prints a local URL, serves one request, closes its listener, and exits.
  • Foundations brings together exact numbers, byte conversion, Options, Results, and persistent Maps.
